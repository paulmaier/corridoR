# corridoR: migration corridors and genetic range shifts

Tools for modeling genetic connectivity along migration corridors and
forecasting how it shifts under climate change. Start with
[`vignette("corridoR")`](https://paulmaier.github.io/corridoR/articles/corridoR.md)
for a short version of the workflow; the full six-step tutorial is at
<https://paulmaier.github.io/corridoR/articles/tutorial.html>.

## Citation

If you use corridoR, please cite both the 2022 paper that introduced the
method (Maier et al. 2022, Heredity 129:257-272,
[doi:10.1038/s41437-022-00561-x](https://doi.org/10.1038/s41437-022-00561-x)
) and the software paper. Run `citation("corridoR")` for both.
